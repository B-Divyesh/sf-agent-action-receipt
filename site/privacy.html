Sample data

The demo keeps its receipt chain in page memory. Resetting or closing the page discards it.

Library data

The npm package makes no network requests. It hashes authorities, arguments, results, and failures before storing receipts.

Optional redacted views appear only when your code supplies them. The package never stores signing keys.

Privacy requests

This site holds no account or sample data to retrieve or delete. Ask your package operator about receipts stored in its systems.
